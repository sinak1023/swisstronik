پاپ‌آپ نصب وب‌اپ به سبک اپ‌استور با پوشش تمام‌صفحه، گالری اسکرین‌شات و راهنمای اختصاصی هر مرورگر.

== Description ==

نسخه حرفه‌ای «افزودن به صفحه اصلی» با امکانات:

* پاپ‌آپ Bottom Sheet یا تمام‌صفحه با بک‌دراپ بلور که کل صفحه را می‌پوشاند
* هدر شبیه اپ‌استور: آیکون، نام، دامنه، برچسب «رایگان»
* گالری اسکرین‌شات قابل اسکرول
* کارت ویژگی‌ها (آفلاین، سرعت، تمام‌صفحه)
* دیالوگ نصب بومی اندروید/کروم (beforeinstallprompt)
* راهنمای مرحله‌به‌مرحله برای iOS Safari ،Chrome iOS ،Firefox iOS ،Samsung Internet ،Firefox Android و Safari مک — با فلش انیمیشنی به سمت دکمه اشتراک‌گذاری
* تشخیص مرورگرهای داخلی (اینستاگرام، تلگرام، فیس‌بوک و…) + دکمه کپی لینک
* حالت تیره خودکار، RTL کامل، سوایپ برای بستن
* کنترل فرکانس نمایش: تأخیر، حداکثر دفعات، فاصله بعد از بستن، حداقل بازدید
* شورت‌کد [a2hs_button] و اتریبیوت data-a2hsp-open برای باز کردن دستی
* منیفست کامل (screenshots ،display_override ،maskable icon) + سرویس‌ورکر با کش آفلاین
* پنل تنظیمات تب‌بندی‌شده با آپلودر رسانه و انتخابگر رنگ — همه متن‌ها قابل ویرایش

== Installation ==

1. پوشه add-to-homescreen-pro را در wp-content/plugins آپلود کنید.
2. پلاگین را فعال کنید.
3. از منوی تنظیمات → A2HS Pro آیکون، اسکرین‌شات‌ها و متن‌ها را تنظیم کنید.
4. سایت باید روی HTTPS باشد.
