# راهنمای ارتقا و راه‌اندازی (CRM فروش)

این نسخه شامل افزونه‌ها و رفع‌باگ‌های گسترده‌ای است. برای فعال‌شدن کامل امکانات، مراحل زیر را یک‌بار انجام دهید.

## ۱) اجرای مهاجرت دیتابیس (الزامی)

اسکریپت `migrate.php` تمام جدول‌ها و ستون‌های جدید را به‌صورت **امن و قابل‌تکرار** می‌سازد
(در صورت وجود، رد می‌شود). یک‌بار اجرا کنید:

```bash
php migrate.php
```

یا از طریق مرورگر:

```
https://YOURDOMAIN/crm/migrate.php?key=crm_migrate_2024
```

> پس از اجرا، فایل `migrate.php` را حذف یا کلید آن را تغییر دهید.

تغییرات اسکیما:
- جدول‌های جدید: `settings`, `sales`, `call_logs`, `message_logs`, `activity_logs`
- ستون‌های لید: `whatsapp_phone`, `telegram_phone`, `telegram_id`, `bale_phone`, `called`, `called_at`, `phone_norm`
- `user_tasks.task_date` (تسک روزانه)
- `users.telegram_chat_id` (آیدی عددی تلگرام)
- `reminders.pre_notified` (اعلان ۵ دقیقه قبل)
- `lead_notes.created_at`
- `lead_numbers.phone_norm`

## ۲) تنظیمات سیستم (از پنل)

به منوی **تنظیمات سیستم** بروید و موارد زیر را وارد کنید:
- پنل پیامک فعال: **آی‌پی‌پنل** یا **ملی‌پیامک** + اعتبارنامه‌ها
- توکن بات تلگرام
- شماره موبایل و آیدی عددی تلگرام **مدیر** (برای دریافت اعلان فروش)

این مقادیر جایگزین مقادیر هاردکدِ `config.php` می‌شوند.

## ۳) کرون‌جاب‌ها

یادآوری‌ها (۵ دقیقه قبل از زمان، پیامک + تلگرام به کارشناس) — هر دقیقه:

```cron
* * * * * php /path/to/crm/cronjobs/send_remindes.php >/dev/null 2>&1
```

> تسک‌های روزانه نیازی به کرون «ریست» ندارند؛ چون بر اساس `task_date = CURDATE()`
> فیلتر می‌شوند، هر روز به‌صورت خودکار از نو شروع می‌شوند و سابقهٔ روزهای قبل برای
> گزارش‌های مدیریتی حفظ می‌شود.

## ۴) دسترسی‌ها (نقش‌ها)

از صفحهٔ **مدیریت نقش‌ها** این دسترسی‌های جدید را به نقش مدیر بدهید:
- «تنظیمات سیستم» و «ذخیره تنظیمات سیستم»
- «گزارش‌های مدیریتی»
- «تعیین نوع پرداخت فروش»

صفحهٔ «فروش‌های من» برای همهٔ کارشناسان بدون نیاز به دسترسی در دسترس است.

## نکات امنیتی (پیشنهادی)

- توکن‌ها و رمزهای واقعی در `config.php` و `apis/check_transactions.php` هاردکد شده‌اند؛
  پیشنهاد می‌شود آن‌ها را بچرخانید (rotate) و به تنظیمات/متغیر محیطی منتقل کنید.
- پس از اجرای مهاجرت، دسترسی به `migrate.php` را ببندید.
