# 🎧 بات پشتیبانی بله + پنل مدیریت و پشتیبان

سامانه‌ی کامل پشتیبانی ریل‌تایم برای پیام‌رسان **بله** (Bale) شامل:

- **بات بله** که فلوی قوانین → تایید → ارسال ویس خوش‌آمد → پشتیبانی را اجرا می‌کند.
- **پنل مدیریت (ادمین)** برای تعریف پشتیبان‌ها، توزیع درصدی کاربران، آمار کامل، نظرسنجی و گزارش رضایت.
- **پنل پشتیبان** با رابط چت تلگرام‌مانند (ریپلای، ویس، عکس/ویدیو/فایل، پین پیام، رضایت/نارضایتی).
- ارتباط **ریل‌تایم** با Socket.IO و مدیریت **محدودیت ارسال** بله (rate-limit) با نوتیف.

> طراحی شده توسط تیم دستیارتو

---

## ⚙️ نصب و راه‌اندازی

```bash
cd bale-support-bot
cp .env.example .env      # سپس مقادیر را ویرایش کنید
npm install
npm start
```

سپس مرورگر را باز کنید:

| صفحه | آدرس |
|------|------|
| ورود | `http://localhost:3000/` |
| پنل ادمین | `http://localhost:3000/admin` |
| پنل پشتیبان | `http://localhost:3000/agent` |

ادمین اولیه از روی `.env` (`ADMIN_USERNAME` / `ADMIN_PASSWORD`) در اولین اجرا ساخته می‌شود.

### دریافت توکن بات
از طریق **@BotFather** در بله یک بات بسازید و `BALE_BOT_TOKEN` را در `.env` قرار دهید.
بدون توکن، پنل کار می‌کند ولی بات غیرفعال است.

---

## 🧭 جریان کاربر (بات)

1. کاربر `/start` می‌زند → متن **قوانین** به همراه دکمهٔ «✅ قوانین را می‌پذیرم» ارسال می‌شود.
2. با زدن دکمه، عبارت «✅ قوانین را تایید کردم» به انتهای متن اضافه می‌شود.
3. کاربر بر اساس **توزیع درصدی** به یک پشتیبان اختصاص می‌یابد و **ویس خوش‌آمد** آن پشتیبان (یا ویس پیش‌فرض) ارسال می‌شود.
4. از این پس همهٔ پیام‌های کاربر ریل‌تایم به پنل پشتیبان می‌رسد.

کاربر تا زمانی که ادمین جابه‌جا نکند، روی همان پشتیبان باقی می‌ماند.

## 👮 امکانات پنل ادمین

- **داشبورد و آمار:** روزانه/هفتگی/ماهانه و قابل جستجو بر اساس تاریخ — برای هر پشتیبان: کل کاربران، دریافتی، خوانده‌شده، پاسخ‌داده، در انتظار، رضایت، نارضایتی.
- **تعریف پشتیبان:** نام، توضیحات، عکس، ویس خوش‌آمد، نام کاربری و رمز ورود.
- **توزیع درصدی:** سهم هر پشتیبان (وزن) قابل تنظیم؛ پیش‌فرض مساوی. توزیع کاربران بر اساس کسری نسبت به سهم هدف.
- **مشاهدهٔ کاربران هر پشتیبان** و خواندن کامل چت‌ها + امکان انتقال کاربر.
- **نظرسنجی:** انتخاب پشتیبان و بازهٔ زمانی (۱ تا ۴ هفته و ۴+)، ارسال دکمه‌ای امتیاز ۱ تا ۵ به‌صورت throttle-شده (بدون خوردن محدودیت بله)، و مشاهدهٔ تعداد رای و میانگین امتیاز. قابل تکرار.
- **گزارش رضایت/نارضایتی** با فیلتر پشتیبان/نوع/تاریخ/کاربر و مشاهدهٔ دلیل ثبت‌شده.
- **تنظیمات بات:** ویرایش متن قوانین و ویس خوش‌آمد پیش‌فرض.

## 🎧 امکانات پنل پشتیبان

- **داشبورد** آمار شخصی (روزانه/هفتگی/ماهانه + جستجوی تاریخ).
- **چت تلگرام‌مانند:** لیست گفتگوها، ریپلای، ارسال عکس/ویدیو/فایل/متن، **پین پیام** و نوار پیام‌های پین‌شده.
- **ضبط ویس داخل مرورگر** (مثل تلگرام): دکمهٔ 🎤 → ضبط با تایمر → ارسال/لغو. خروجی مستقیماً با فرمت **OGG/Opus** (سازگار با `sendVoice` بله) تولید می‌شود.
- **Paste کردن عکس** مستقیم در کادر پیام.
- دکمه‌های **رضایت/نارضایتی** کنار نام کاربر (روزانه) با ثبت دلیل (فقط برای ادمین).
- نمایش لحظه‌ای پیام‌های جدید.

### 🎙️ نکته دربارهٔ ضبط ویس
طبق مستندات بله، متد `sendVoice` تنها فایل `audio/ogg` را می‌پذیرد. مرورگر کروم به‌صورت پیش‌فرض `webm` ضبط می‌کند؛ به همین دلیل ضبط مستقیماً با کتابخانهٔ **opus-recorder** (در `public/vendor/`) به‌صورت **OGG/Opus** انجام می‌شود و روی همهٔ مرورگرها (کروم، فایرفاکس، موبایل) بدون نیاز به `ffmpeg` یا تبدیل سمت سرور کار می‌کند. ویس خوش‌آمد آپلودی اگر `.ogg` نباشد به‌صورت فایل صوتی (`sendAudio`) ارسال می‌شود.

## 🏗️ معماری

```
src/
  config.js          تنظیمات از .env
  db.js              SQLite + schema
  util.js            توابع تاریخ
  realtime.js        پل Socket.IO
  bale/
    api.js           کلاینت API بله + rate-limiter سراسری + هندل 429
    messaging.js     ارسال و ذخیرهٔ پیام‌ها
    bot.js           حلقهٔ polling و فلوی کاربر
  services/
    assignment.js    منطق توزیع درصدی
    stats.js         آمار روزانه/هفتگی/ماهانه
    survey.js        ارسال نظرسنجی throttle-شده
    settings.js      تنظیمات (قوانین، ویس)
  web/
    server.js        Express + Socket.IO
    auth.js          JWT + bcrypt
    routes/          auth, admin, agent, media
public/              فرانت‌اند RTL و رسپانسیو (login/admin/agent)
```

### ارسال بدون انتظار (Optimistic) + مقیاس‌پذیری
- پیام پشتیبان **فوری** در UI نمایش داده می‌شود (با آیکن 🕓) و در پس‌زمینه به بله تحویل می‌شود؛ پس از تحویل به ✓ تبدیل می‌شود و در صورت خطا ⚠️ (با کلیک، تلاش مجدد). پشتیبان لازم نیست منتظر بماند و می‌تواند از چت خارج شود.
- برای هندل **۱ تا ۲ هزار کاربر**: ایندکس‌های دیتابیس، pragmaهای WAL/NORMAL، و **جستجوی سمت سرور** در لیست چت پشتیبان و لیست کاربران هر پشتیبان (پنل ادمین).

### مدیریت محدودیت ارسال (Rate limit)
همهٔ درخواست‌های خروجی به بله از یک صف سریالی با حداقل فاصلهٔ `BALE_MIN_INTERVAL_MS` عبور می‌کنند.
در صورت دریافت خطای ۴۲۹، مقدار `retry_after` استخراج شده و:
- در ارسال پشتیبان → پاپ‌آپ هشدار با زمان انتظار نمایش داده می‌شود.
- در نظرسنجی → ارسال به‌طور خودکار پس از زمان لازم ادامه می‌یابد.
